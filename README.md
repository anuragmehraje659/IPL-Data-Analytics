🏏 IPL Data Analytics & Dashboard

An end-to-end IPL Data Analytics project built using Python, SQL, MySQL, Power BI, and Streamlit to analyze IPL seasons, teams, players, runs, wickets, and performance.
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
📊 Project Overview

This project demonstrates a practical data analytics workflow:

1. 📥 Load and prepare IPL dataset

2. 🧹 Perform data cleaning and transformation using Python

3. 🗄️ Store and analyze structured data using MySQL

4. 🔍 Use SQL queries for team and player analysis

5. 📊 Build interactive Power BI and Streamlit dashboard components

6. 📈 Create visualizations for runs, players, teams, and wickets
